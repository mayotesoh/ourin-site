# Notionブログ連携 セットアップ手順

サイトの「活動報告」（`/blog`）は、**Notionに書いた記事がそのまま公開される**仕組みです。
この手順どおりに進めれば連携が完了します。所要 15〜20分ほど。

---

## STEP 1｜Notion AI にデータベースを作らせる

Notionの適当なページを開き、`スペースキー`（またはNotion AIボタン）で AI を呼び出して、
**下のプロンプトをそのまま貼り付けて**送信してください。

### 📋 コピペ用プロンプト

```
「活動報告ブログ」という名前のデータベース（テーブルビュー）を作ってください。
Webサイトと自動連携するため、プロパティ名は以下の通り一字一句正確にお願いします。

【プロパティ】
1. タイトル … タイプ：タイトル
2. 日付 … タイプ：日付（記事の公開日）
3. ステータス … タイプ：セレクト。選択肢は「下書き」「公開」の2つだけ。既定値は「下書き」
4. カテゴリー … タイプ：マルチセレクト。選択肢は「定例会レポート」「イベント出店」「お知らせ」「スキルアップ講座」「日々のこと」
5. URLスラッグ … タイプ：テキスト（例：event-2026-09 のような半角英数字とハイフン）
6. アイキャッチ … タイプ：ファイル&メディア（記事のトップ画像。空でもOK）
7. 概要 … タイプ：テキスト（一覧に出る2〜3行の説明文）

【ビュー】
・既定のテーブルビューは「日付」の降順で並べる
・「公開済み」というビューを追加し、ステータスが「公開」のものだけを表示、日付の降順

【サンプル記事】
上記のデータベースに、サンプル記事を1件作成してください。
・タイトル：占いコミュニティ、いまのカタチ ― 定例会レポート
・日付：今日
・ステータス：下書き
・カテゴリー：定例会レポート
・URLスラッグ：community-report-01
・概要：3月の始動から半年。オンライン定例会とリアル交流会の様子、メンバーの活動の広がりをレポートします。
・本文には、見出し（H2）「オンライン定例会」「リアル定例会の様子」「活動の場も広がっています」「これからの展望」を作り、
　それぞれに本文を書ける空の段落を置いてください。

【最後に】
このデータベースの「使い方メモ」を、データベースの上に3行で書いてください。
（記事を書く→ステータスを「公開」にする→翌朝サイトに反映される、という流れ）
```

> 💡 Notion AI がうまく作れなかった項目は、手で直してもOKです。
> **大事なのはプロパティ名（タイトル／日付／ステータス／カテゴリー／URLスラッグ／アイキャッチ／概要）が一致していること**だけです。

## STEP 2｜インテグレーション（APIキー）を作る

1. https://www.notion.so/my-integrations を開く
2. 「新しいインテグレーション」→ 名前は「松山倫子サイト」など何でもOK
3. 関連ワークスペースを選んで作成
4. 表示された **内部インテグレーションシークレット**（`ntn_` で始まる文字列）をコピー
   → これが `NOTION_API_KEY` です。**他人に見せない**でください

## STEP 3｜データベースをインテグレーションに接続

1. STEP 1 で作った「活動報告ブログ」のページを開く
2. 右上の `•••` →「接続」→ STEP 2 で作ったインテグレーションを選ぶ

> ⚠️ これを忘れると、サイト側から見えず記事が0件のままになります（いちばん多いつまずきポイント）

## STEP 4｜データベースIDを調べる

データベースを開いたときのURLを見ます。

```
https://www.notion.so/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=yyyyyyyy...
                      └────────── この32桁が「データベースID」──────────┘
```

`?v=` より前の32桁が `NOTION_BLOG_ID` です。

## STEP 5｜GitHubに登録する（本番サイト用）

1. https://github.com/mayotesoh/ourin-site を開く
2. Settings → Secrets and variables → Actions → **New repository secret**
3. 次の2つを登録

| Name | Secret |
| --- | --- |
| `NOTION_API_KEY` | STEP 2 でコピーした `ntn_…` |
| `NOTION_BLOG_ID` | STEP 4 の32桁 |

4. Actions タブ →「Deploy to GitHub Pages」→ Run workflow で手動実行

これで `/blog` に記事が出ます。以降は **毎朝7時（日本時間）に自動で再ビルド**されるので、
Notionでステータスを「公開」にすれば翌朝には反映されます。すぐ反映したいときは同じ手順で手動実行してください。

## STEP 6｜手元で確認したい場合（任意）

`.env.example` をコピーして `.env` を作り、同じ値を書きます。

```
NOTION_API_KEY=ntn_xxxxxxxxxxxx
NOTION_BLOG_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

`npm run dev` で http://localhost:4321/blog を開くと確認できます。
（`.env` は絶対にGitHubにアップしないでください。`.gitignore` で除外済みです）

## 記事の書き方

Notionに普通に書くだけです。以下に対応しています。

| Notionの書式 | サイトでの表示 |
| --- | --- |
| 見出し1〜3 | 見出し |
| 箇条書き・番号付きリスト | リスト |
| 引用 | 引用（左に緑の線） |
| コールアウト | 囲みメモ |
| 画像 | 画像（キャプションつき） |
| YouTubeの埋め込み・URL貼り付け | 動画プレイヤー |
| トグル | 開閉できる見出し |
| 区切り線・太字・リンク | そのまま |

**公開の条件**：ステータスが「公開」であること。それ以外（下書き）はサイトに出ません。

## トラブルシューティング

| 症状 | 原因と対処 |
| --- | --- |
| 記事が1件も出ない | STEP 3 の「接続」を忘れている／IDが違う |
| 一部の記事だけ出ない | ステータスが「公開」になっていない |
| 画像が表示されない | Notionにアップした画像のURLは期限つきです。毎朝の再ビルドで更新されますが、確実にしたい場合は外部URL（Instagram等ではなく画像の直リンク）を使うか、再ビルドしてください |
| 記事のURLを変えたい | 「URLスラッグ」を書き換える（空ならページIDが使われます） |
| 反映が待てない | GitHubの Actions タブから手動実行 |
